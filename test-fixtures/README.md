# Fixtures de domínio

Dados exclusivamente sintéticos usados pelos testes de Flutter, Cloud Functions e .NET.

- `domain/phone_normalization_cases.json`: contrato compartilhado da normalização de telefone.
- `domain/billing_cases.json`: contrato compartilhado do status financeiro efetivo.
- `firestore/legacy_shared_phone.json`: formato legado mínimo para duas alunas com o mesmo telefone do responsável.

Nenhuma fixture deve conter dado copiado de produção.
